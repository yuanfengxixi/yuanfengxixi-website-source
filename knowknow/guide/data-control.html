数据管理 · 约 2 分钟

你的笔记，
应该由你掌握。

知知提供导出和回收站，让内容可带走，也给误删留一个恢复机会。

如何导出笔记？

  1. 在小程序“我的”页面点“导出我的数据”，进入笔记选择页。
  2. 选择一篇或多篇笔记，再点“导出所选”。要导出全部笔记时，先清空搜索条件，再点“全选”，确认已选数量后点“导出所选”。
  3. 单篇导出为 Markdown 文件（.md）；多篇或全选导出为 Markdown ZIP 压缩包。文件准备好后，点“发送到微信”，再按微信提示选择发送对象。

单篇 Markdown 可在支持 Markdown 的工具中打开；ZIP 包内按笔记目录整理文件。

删除后还能恢复吗？

普通删除会先把笔记和目录移到回收站。你可以在回收站查看并恢复误删内容；如果要彻底删除，需要再次确认。彻底删除后不再享有回收站恢复保护。

AI 的回答是否需要核对？

需要。知知可以帮助查找、整理和思考，但 AI 结果可能不准确。涉及重要事实、决定或个人信息时，应查看原笔记并自行确认。

知知不会把聊天中发送的图片或文件一律自动写进笔记。它们先作为当前消息的上下文，只有实际决定写入时才保存。
